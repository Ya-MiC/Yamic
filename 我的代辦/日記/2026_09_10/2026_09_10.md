#使用提示 
GitHub 請閱讀 Ya-MiC/zhanzhen-panel 的 PROJECT_CONTEXT.md、ARCHITECTURE.md、TODO.md、CHANGELOG.md 與最近 5 個 commits，從目前狀態繼續實作；不要覆蓋既有功能，只做增量修改。  
## Non-negotiable rules  
  
1. v0.1 的完整三欄面板（左側導航、首頁、文件、本地保存、讀書分析、流程圖、思路画像、寫作工坊、右側 AI 助手、雙主題）必須保留。  
2. 新功能一律以增量方式接入；不得以新的簡化頁面替換 App.vue 或刪除既有業務。  
3. 未真正實作的功能必須標示為「規劃中／開發中」，不得宣稱已支持。  
4. 真實客戶文件、API Key、聊天記錄與私密資料不得提交到 GitHub。  
5. 每個可用功能完成並由用戶驗收後，必須先提交 Git；main 僅保留已驗收、可運行版本。  
長工程的協作節奏  
每一輪只完成一個可驗收閉環，例如：  
格式提示閉環：MD/TXT 正常導入；DOCX/XLSX/PDF 彈出提示；PDF 有 PDF24 自願外鏈。  
CSV/TSV 表格閉環：選文件、真實表格顯示、篩選、保存本地修改。  
插件骨架閉環：插件註冊、啟用/停用、面板出現在工作區。  
聊天導入閉環：先支援一種格式，使用者選 JSON/JSONL 檔後可預覽、確認、導入本地。  
部署閉環：Cloudflare Pages 預覽環境可構建、正式分支可展示。  
桌面閉環：Tauri 打包後能選本地文件、保存、讀取工作區配置。  
每個閉環都要有：  
text  
需求 → 文件列表 → 實作 → 本地測試 → Git commit → GitHub 推送 → CHANGELOG
