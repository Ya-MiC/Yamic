# ⑥ 所以不要把自己的雷达图做成“越像 Elon 越好”

这是我特别建议你注意的。

如果你的算法最后变成：

> 与 Elon 的欧氏距离越小 = 越优秀

那你的算法本身就是错的。

因为：

**Jensen Huang ≠ Elon**

**Jeff Bezos ≠ Elon**

**Patrick ≠ Elon**

**CZ ≠ Elon**

**孙宇晨 ≠ Elon**

但他们都能建立极大的现实影响。

所以你的 Excel 最好做：

### A. Absolute Score

你当前能力是多少。

### B. Relative Score

相对于 20 / 30 / 50 岁平均值是多少。

### C. Builder Distance

距离某一种 Builder 类型还有多少。

### D. Growth Rate

每年提高多少。

# ⑨ 甚至可以做一个“湛箴16年指数”

我建议你不要只算平均分。

因为平均分会掩盖短板。

例如：

> 认知 90  
> 商业 40  
> 执行 40

简单平均：

> 56.7

看起来还行。

但真实情况是：

> **短板把整个系统卡住了。**

所以你可以做两个指数。

### 综合能力指数

```
=AVERAGE(B2:AE2)
```

### 系统平衡指数

```
=MIN(B2:AE2)
```

然后：

### Builder Index

可以先简单做：

```
=0.35*认知+0.20*系统+0.15*技术+0.15*商业+0.15*执行
```

但我更建议你以后自己设计权重。

因为**你的16年目标不是复制任何一个人。**
