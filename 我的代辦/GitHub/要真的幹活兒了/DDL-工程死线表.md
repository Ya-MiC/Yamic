## M1 · 编辑器 MVP（09-14 → 10-11）

- [ ] 第 1 周：Vite + Vue 3 + TipTap 跑通，Proton 风格界面骨架（左文档右面板）
- [ ] 第 2 周：块系统 + 拖拽排序（TipTap drag handle），支持标题/段落/表格/图片块
- [ ] 第 3 周：docx 导入导出（docx.js），xlsx 表格块（SheetJS）
- [ ] 第 4 周：自动保存（SQLite/本地文件）、暗色模式、里程碑评审

**卡点预案**：拖拽不顺就先用「上移/下移」按钮替代，不阻塞进度。

## M2 · 读书 skill（10-12 → 11-08）

- [ ] 第 1 周：文档解析管线——docx/pdf → 结构化章节树
- [ ] 第 2 周：思路提取 Prompt 链——论证结构、句式指纹、术语表（见 SKILLS.md）
- [ ] 第 3 周：sqlite-vec 向量库，历史报告切块入库
- [ ] 第 4 周：画像 JSON 生成 + 画像可视化面板（让用户看到 AI 学到了什么）

**验收**：上传事务所 5 篇审计报告，产出的画像能说出「我们的报告先讲结论还是先摆证据」。

## M3 · 女娲 skill（11-09 → 12-06）

- [ ] 第 1 周：思路大纲生成——检索画像 + 相似段落，先出大纲不急着写正文
- [ ] 第 2 周：分段生成——用户在右侧 AI 面板逐段确认/重写
- [ ] 第 3 周：自检环节——对照画像检查术语一致性、披露完整性
- [ ] 第 4 周：**家人盲测**——AI 写的和所里写的混在一起，看能不能被认出来

**验收**：盲测通过即 M3 完成；通不过则把差异写回画像，迭代一轮。

## M4 · 多语言（12-07 → 12-27）

- [ ] 第 1 周：vue-i18n 接入，界面中/英切换
- [ ] 第 2 周：文档翻译块（Argos Translate 本地离线 / LLM 翻译二选一）
- [ ] 第 3 周：思源黑体/宋体 + Lucide 图标全量替换，字体子集化减小体积

## M5 · 三端打包（12-28 → 01-24）

- [ ] 第 2 周：Windows exe 构建 + 签名 + 安装包，真机测试
- [ ] 第 3 周：Android APK 构建，移动端布局适配（块面板改为底部抽屉）
- [ ] 第 4 周：应用商店材料（截图、简介、隐私政策），提交审核
