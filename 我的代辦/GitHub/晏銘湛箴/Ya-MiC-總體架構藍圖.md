## 每一層在解決什麼問題

| 層 | 回答的問題 | 現況 |
|---|---|---|
| 資料來源層 | 我的東西存在哪裡？ | GitHub、Notion 已接；Google 待接 |
| 自動化層 | 有新東西出現時，誰去發現它？ | 部分已有，需補齊定時同步 |
| 資料整合層 | 這些散落的東西，統一存成什麼格式？ | 尚未真正建立 |
| 分類層 | 每一筆東西該貼什麼標籤？ | GitHub 那塊做完了，檔案類型那塊沒做 |
| 呈現層 | 使用者（就是你）怎麼看到這一切？ | 網頁版有，桌面版沒做 |

# 第六部分：免費 vs 要花錢，一次列清楚

## 6.1 現階段（產品 A，你正在做的）——幾乎全免費

```text
✅ GitHub 帳號              免費
✅ GitHub Actions           免費（你的用量遠遠用不到額度上限）
✅ Netlify 網頁託管          免費額度內
✅ Notion                  你已經在用，個人版免費
✅ 前端技術（HTML/CSS/JS）   免費，不用任何授權
✅ Tauri 桌面打包            免費，開源工具
✅ 知識圖譜視覺化元件         免費（MIT 授權）

目前為止，產品 A 你已經花的錢 = 0 元
```

## 6.2 未來會開始花錢的地方（產品 B，還沒到）

```text
💰 大模型 API 調用（GLM-5.3-Flash / DeepSeek）
   → 但可以先用 Kaggle/Colab 免費算力做實驗，正式上線才需要付費 API

💰 VPS 伺服器（跑 n8n/Dify/Logto 自托管版本）
   → 若用免費層 Cloud 服務（如 Cloudflare Workers 免費額度）可以延後這筆支出

💰 中國大陸簡訊驗證碼（如果要接手機號登入）
   → 約 0.04–0.05 元/條，新用戶通常有 100-200 條免費額度

💰 微信登入認證（如果要接微信登入）
   → 約 300 元/年，只有真的要做中國大陸版才需要

💰 域名（如果要脫離 xxx.netlify.app 這種預設網址）
   → 約 60-100 元/年，可選，不是必需

💰 Apple Developer Program（如果未來要上架 iOS App）
   → 約 688 元/年（99 美元），只有做手機 App 才需要
```

**現階段（產品 A）你不需要花一分錢；產品 B 要花錢的地方，全部發生在「有真實客戶要用」之後，現在完全不用擔心。**
